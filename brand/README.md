# Kuku brand

- `kuku-icon.svg`: the master app icon (vector, 1024 × 1024): a white speech
  bubble saying "ku" with a yellow notification dot, on indigo.
- Colours: indigo `#4338CA` (brand), yellow `#FBBF24` (accent), white.
- Wordmark: "kuku" in lowercase, Inter Display ExtraBold/Black.

The PNG icons the site uses (`src/app/icon.png`, `src/app/apple-icon.png`,
`src/app/favicon.ico`, `public/icons/*`) are exported from this file.
